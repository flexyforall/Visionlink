## Постоянные правила
- Шрифты проекта Switzer / Supreme только через текстовые стили, Inter в макете не оставлять.
- Плоский минималистичный стиль, радиусы 2–4, как на главной. Цвета — через переменные Theme (коллекция `VariableCollectionId:1073:3`, Light mode `1157:0`, Dark по умолчанию); внутренности иллюстраций можно сырыми цветами.
- Переиспользовать компоненты. Мобилка 390, поля 20.
- Проверять результат скриншотом. Спорить, если не согласна. Не выдумывать реальные отзывы, заглушки помечать.

## Обходы ограничений Figma API
- Switzer/Supreme не загружаются. Текст создавать в Inter, задать размер, затем `textStyleId` — работает без загрузки шрифта.
- `setProperties` у компонентов с текстом на Switzer падает. Обход: временно заменить тексты в вариантах на Inter-копии (сохранив `componentPropertyReferences`), выставить свойства экземплярам, вернуть `textStyleId`. Так сделано для `Steps nav / Item` (`1481:1062`).
- Цвет с переменной: `figma.variables.setBoundVariableForPaint(paint,'color',variable)`.
